WHAT IT DOES

From requests to useful context.

01 / ANALYSE

Attack Intelligence

Import IIS logs, review client requests, investigate suspicious traffic and inspect verified crawler activity.

02 / UNDERSTAND

User Insights

Explore website searches and estimated browsing journeys, with successful-order information from a read-only order API.

03 / REVIEW

Check Error Emails

Compare IP addresses found in unread Gmail alert subjects with imported logs, then organise those messages according to the configured review rules.

GMAIL CONNECTION

Authorised access.
A specific purpose.

The operator connects the designated Gmail account through Google's OAuth sign-in. LogLens requests gmail.modify permission to read message metadata and change labels, read status, stars and Trash status.

The email review runs when the operator clicks Check Error Emails. LogLens does not send Gmail messages or permanently delete them through the API. It does not request the Gmail account password.

Gmail data and credentials are not published on this site. See the privacy policy for access, storage, retention and revocation details.
